# AbstractClassroom Code Assignments workflows

Shared source verification, protected-file restoration, and JWT issuance for
[Code Assignments](https://preview.abstractclassroom.com/code-assignments/).
Implementation and documentation live here so the
[instructor starter](https://github.com/abstractclassroom/code-assignments-template)
contains only `.github/workflows/auto-grading-workflow.yml`.

**Do not rename `auto-grading-workflow.yml`.** AbstractClassroom checks that exact
file against the registered instructor source.
